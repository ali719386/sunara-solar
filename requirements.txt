SUNARA solar website: requirements
===================================

This is a Node.js (Next.js) project, not Python. Packages are installed with
"npm install" from package.json and package-lock.json; this file only lists
what you need around them. Full setup steps are in README.md.


1. Software
-----------
- Node.js 20 or newer (developed on Node 24.19)
- npm 10 or newer (comes with Node; developed on npm 11.17)
- Git
- A modern browser (Chrome, Edge, Firefox or Safari)


2. Accounts and keys
--------------------
Put keys in .env.local (copy .env.example). Never commit them.

Required for AI features
- Google Gemini API key  -> GEMINI_API_KEY
  https://aistudio.google.com/apikey
  Powers the chatbot and the calculator's AI advice. Without it the site still
  works with built-in answers. The free tier is very small; enable billing for
  real visitors.

Optional
- NLR (formerly NREL) API key -> NLR_API_KEY
  https://developer.nlr.gov/signup/   (free)
  Only for re-running scripts/build-state-sun.mjs. Not needed on Vercel.
- WhatsApp number -> NEXT_PUBLIC_WHATSAPP_NUMBER (digits, country code first)
- Site URL and social links -> NEXT_PUBLIC_SITE_URL, NEXT_PUBLIC_SOCIAL_*

Hosting
- GitHub repository: ali719386/sunara-solar (push to main deploys)
- Vercel project connected to that repository, with GEMINI_API_KEY set

4. Data sources used by the calculator
--------------------------------------
- US Energy Information Administration (EIA), 2024 residential rates and bills
  https://www.eia.gov/electricity/sales_revenue_price/
- NREL based annual peak sun hours by state (Unbound Solar table)
  https://unboundsolar.com/solar-information/sun-hours-us-map
- NLR (formerly NREL) PVWatts v8 / NSRDB monthly sun data, via
  scripts/build-state-sun.mjs (bundled in lib/stateSun.ts)
- OpenStreetMap Nominatim for city locations (same script)
  Location data (c) OpenStreetMap contributors


5. Quick check after setup
--------------------------

  npm run typecheck
  npm run lint
  npm test
  npm run dev        then open http://localhost:3000
